# Changelog

### Breaking Changes 🚨

- `fc102f4` The 4/3-way valve position and the active heating program sensors now report lowercase states, for example `domestic_hot_water` instead of `domesticHotWater` and `normal_heating` instead of `normalHeating`. Update automations and templates that compare the raw values; the climate attribute `active_program` keeps the raw API value. ([#229](https://github.com/ignazhabibi/vi_climate_devices/pull/229))

### New Features 💫

- `e77283d` Add daily energy sensors for electricity consumption (heating, DHW) and heat production (heating, DHW, cooling), and document template examples for totals, COP, environmental heat, and supply/return spread. ([#226](https://github.com/ignazhabibi/vi_climate_devices/pull/226))
- `fc102f4` Translate the active program per heating circuit and the 4/3-way valve position, and add summer eco, holiday, and holiday-at-home binary sensors. ([#229](https://github.com/ignazhabibi/vi_climate_devices/pull/229))

### Other Changes ☀️

- `e77283d` Upgrade vi_api_client to v6.1.0. ([#226](https://github.com/ignazhabibi/vi_climate_devices/pull/226))
- `5acbe28` Remove the unused climate preset mapping; the active program stays available as the `active_program` attribute. ([#228](https://github.com/ignazhabibi/vi_climate_devices/pull/228))

### Bug Fixes 🐞

- `5acbe28` Use the matching heating or cooling setpoint for energy-saving programs on heat pumps with cooling, and support the E3 heating/cooling operating mode. ([#228](https://github.com/ignazhabibi/vi_climate_devices/pull/228))
