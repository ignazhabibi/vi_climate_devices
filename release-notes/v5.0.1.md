# Changelog

### Bug Fixes 🐞

- `bc7a580` Show the `balanced` hot water mode as a water heater operation instead of an unknown operation: gas on Vitodens boilers, heat pump on Vitocal heat pumps. The device family now comes from the device roles the Viessmann API reports, with the family name in the model ID as the fallback, instead of a model ID prefix that real devices do not use. Requires `vi_api_client` 7.1.0. ([#266](https://github.com/ignazhabibi/vi_climate_devices/pull/266))
