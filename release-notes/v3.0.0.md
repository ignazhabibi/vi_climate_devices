# Changelog

### Breaking Changes 🚨

- `faa665b` The noise reduction sensor reports lowercase states (for example `slightly_reduced` instead of `slightlyReduced`), and the one-time charge binary sensor is removed in favor of the existing one-time charge switch. Update automations and templates that use them. ([#232](https://github.com/ignazhabibi/vi_climate_devices/pull/232))

### New Features 💫

- `faa665b` Show heating-circuit and component numbers only when a device has more than one, counted from 1, and use clearer default names in English and German. Entity IDs and custom names are unchanged. ([#232](https://github.com/ignazhabibi/vi_climate_devices/pull/232))
- `faa665b` Translate the noise reduction program and add sensors for the internal pump and the outside temperature damping factor. ([#232](https://github.com/ignazhabibi/vi_climate_devices/pull/232))

### Other Changes ☀️

- `faa665b` Name the 4/3-way valve positions by function (heating/cooling, bypass/defrost buffer, domestic hot water) and align German names and spelling. ([#232](https://github.com/ignazhabibi/vi_climate_devices/pull/232))
