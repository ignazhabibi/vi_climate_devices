# Changelog

### New Features 💫

- `a8c2378` Add a "Heat pump state" sensor (off, pre-run, heating, cooling, preparing defrost, defrosting, post-run) and a "Heating rod" stage sensor, read from the heat pump's active status messages. The state sensor names the code behind its state (`state_code`) and lists all active codes with bus address and local activation time (`active_codes`, not recorded); the heating rod sensor lists the running stages (`active_stages`). Also adds binary sensors for DHW heating, utility lock and grid power limitation; the last two are disabled by default. ([#237](https://github.com/ignazhabibi/vi_climate_devices/pull/237))
- `0b90f01` Add named sensors for the expansion valve openings and the inverter power, current and temperature, enabled by default. Previously these were auto-discovered, disabled on tested devices and named after their feature paths. Existing entity IDs and custom names are kept; entities you already have disabled stay disabled until you enable them. ([#238](https://github.com/ignazhabibi/vi_climate_devices/pull/238))
