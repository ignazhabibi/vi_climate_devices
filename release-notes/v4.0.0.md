# Changelog

### Breaking Changes 🚨

- `c2f21d0` Remove the heating circuit operation mode and DHW mode select entities. Set these modes through the climate entity (`climate.set_hvac_mode`) and the water heater entity (`water_heater.set_operation_mode`) instead, and update automations, scripts and dashboards that use the selects. The old entries stay in the entity registry as unavailable and can be deleted there. ([#244](https://github.com/ignazhabibi/vi_climate_devices/pull/244))

### Other Changes ☀️

- `c2f21d0` Rename "Internal Pump" to "Secondary Circuit Pump" ("Sekundärkreispumpe") and "DHW Circulation Pump" to "Circulation Pump" ("Zirkulationspumpe"). Existing entity IDs and custom names are kept. ([#244](https://github.com/ignazhabibi/vi_climate_devices/pull/244))
