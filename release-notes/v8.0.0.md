# Changelog

### Breaking Changes 🚨

- `2d8d5da` Require Home Assistant 2026.11.0 or newer. The climate and water heater entities use Home Assistant's new `native_*` temperature properties, which older versions do not provide. Climate and water heater entities now also report the `temperature_unit` state attribute. ([#301](https://github.com/ignazhabibi/vi_climate_devices/pull/301))

### Other Changes ☀️

- `44a589a` Describe installation, pre-releases, and removal through the Home Assistant Marketplace. ([#303](https://github.com/ignazhabibi/vi_climate_devices/pull/303))
- `b5a6021` Use Home Assistant's own translation for the successful re-authentication message. ([#302](https://github.com/ignazhabibi/vi_climate_devices/pull/302))
