# Changelog

### Breaking Changes 🚨

- `44393ab` Require `vi_api_client` 7.0.0. Features that Viessmann writes through an on/off command pair (heating circuit comfort, eco and forced-schedule programs, ventilation quick modes) become disabled-by-default switches instead of binary sensors. The DHW hygiene program becomes a switch instead of a binary sensor, and its trigger times become sensors instead of number entities. These entities move to another platform and get new entity IDs, so update automations, scripts and dashboards that use them. The replaced registry entries are removed automatically. Read-only holiday start and end dates no longer create sensors. ([#258](https://github.com/ignazhabibi/vi_climate_devices/pull/258))

### Other Changes ☀️

- `a390518` Read the SCOP sensors from `heating.spf.*` and the outside temperature damping factor from `heating.configuration.temperature.outside.dampingFactor`, the successors of the deprecated features, and fall back to the deprecated features on devices that do not report the successors yet. The existing entities and their history are kept. The auto-discovered duplicate "Spf Dhw", "Spf Heating" and "Spf Total" sensors are removed; on untested devices, where they were enabled by default, use the SCOP sensors instead. ([#262](https://github.com/ignazhabibi/vi_climate_devices/pull/262))
- `e7fa68e` Read the DHW temperature from `heating.dhw.sensors.temperature.dhwCylinder`, the successor of the deprecated `hotWaterStorage` feature, and fall back to the deprecated feature on devices that do not report the successor yet. The existing hot water temperature entity, its history and the water heater are kept. The auto-discovered duplicate "Dhw Sensors Temperature Dhw Cylinder" sensor is removed; on untested devices, where it was enabled by default, use the hot water temperature entity instead. ([#260](https://github.com/ignazhabibi/vi_climate_devices/pull/260))
- `7c9b90f` Group `vi_api_client` dependency updates across both manifests. ([#259](https://github.com/ignazhabibi/vi_climate_devices/pull/259))
